# Granger Plan 2: Reader — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open installed ZIM packs on the phone and read them offline: a Library screen, a WebView reader served straight from the ZIM, title and full-text search across packs, bookmarks, and per-article reading position.

**Architecture:** `:core:zim` is a thin Kotlin facade (`ZimArchive`, `ZimOpener`) over Kiwix's published `org.kiwix:libkiwix` AAR, plus two pure-Kotlin pieces tested on the JVM: `ZimUrls` (reader URL ↔ pack + entry path) and `ZimResolver` (what to serve for a WebView request or link tap). `:core:library` holds the installed-pack registry, bookmarks and reading positions in Room behind a `Library` interface; it finds packs by scanning `<volume>/packs/*.zim` on every external-files volume, which is where Plan 3's downloader will write. `:app` adds navigation and four Compose screens (Library, Reader, Search, Bookmarks) whose ViewModels depend only on `Library` / `LibrarySearch`, so they are tested with fakes.

**Tech Stack:** Kotlin 2.4.21, AGP 9.4.1, Compose BOM 2026.09.00, `org.kiwix:libkiwix:2.6.0`, Room 2.8.5 with KSP 2.3.12, Navigation Compose 2.10.2 (type-safe routes, kotlinx-serialization 1.11.0), Lifecycle 2.11.0, Robolectric 4.17 (Room tests on the JVM), JUnit 4.13.2, Truth 1.4.5, kotlinx-coroutines-test 1.11.0. Test ZIM built with python-libzim 3.13.1.

**Spec:** `docs/superpowers/specs/2026-10-15-granger-v1-design.md` (build-order milestone 2; sections "Modules", "Reading", "Error handling"). Roadmap: `docs/superpowers/plans/2026-10-15-granger-v1-roadmap.md`.

## Review Focus

1. **ZIM paths with URL-special characters** (`C++`, `What_is_this?`, `Café_au_lait`, `100%_Pure`) must open the exact article. `+` is a literal plus, never a space, and `?` must not be cut off as a query string → `ZimUrlsTest` round-trip cases (Task 2), `KiwixZimArchiveTest.readsPathsWithSpecialCharacters` (Task 4), and a reader test that loads `C++` (Task 9).
2. **libkiwix's `SearchIterator` getters describe the result that the *next* call to `next()` returns** (verified in `java-libkiwix/lib/src/main/cpp/libzim/search_iterator.cpp`). Reading the title or snippet after `next()` pairs every snippet with the wrong article → `KiwixZimArchiveTest.fullTextHitsDescribeTheirOwnEntry` (Task 4).
3. **A pack that disappears or is damaged while in use** (SD card removed, file deleted, truncated download, garbage `.zim`) must show as Missing or Damaged, keep its bookmarks, and never crash the reader, search, or other packs → `KiwixZimOpenerTest`, `KiwixZimArchiveTest.callsAfterCloseReturnEmpty`, `concurrentUseAndCloseDoNotCrash` (Task 4); `RoomLibraryTest.unreadableFileIsDamagedAndOthersStillWork`, `deletedFileBecomesMissingAndComesBack` (Task 6); `ZimLibrarySearchTest.oneFailingPackDoesNotHideOthers` (Task 7).
4. **Search input that is Xapian query syntax** (`"unbalanced`, `((`, `AND OR`, `C++`) must return results or nothing, never throw → `KiwixZimArchiveTest.searchSurvivesQueryParserSyntax` (Task 4).
5. **Reading position edge cases:** a zero-height page yields `0/0 = NaN`; a last-read article that no longer exists in an updated pack; leaving the reader with Back before the save finishes → `RoomLibraryTest.savePositionClampsNaNAndRange`, `startPathFallsBackToMainPageWhenLastReadIsGone` (Task 6); `ReaderViewModelTest.positionWritesOutliveTheScreen` (Task 9).

```python
    def get_title(self):
```

### Task 2: Reader URL scheme (`ZimUrls`)

**Files:**
- Create: `core/zim/src/main/kotlin/app/granger/core/zim/ZimUrls.kt`
- Test: `core/zim/src/test/kotlin/app/granger/core/zim/ZimUrlsTest.kt`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `data class ZimUrl(val packId: String, val path: String, val fragment: String? = null)`
  - `object ZimUrls { const val HOST: String; fun forEntry(packId: String, path: String, fragment: String? = null): String; fun parse(url: String): ZimUrl? }`

Reader URLs are `https://zim.granger.invalid/<packId>/<path>`. `.invalid` is a reserved TLD that never resolves, so a request that slips past interception cannot reach the network. Each path segment is percent-encoded as UTF-8 except the RFC 3986 unreserved characters; `/` separates segments so relative links in articles (`../I/foo.png`, `leaf.png`) resolve the way they do in Kiwix. Parsing drops the query string, keeps the raw fragment, and decodes percent escapes without turning `+` into a space.

- [ ] **Step 1: Write the failing test**

```kotlin
package app.granger.core.zim

import com.google.common.truth.Truth.assertThat
import org.junit.Test

class ZimUrlsTest {
    private fun roundTrip(path: String) =
        assertThat(ZimUrls.parse(ZimUrls.forEntry("pack-1", path))).isEqualTo(ZimUrl("pack-1", path))

    @Test fun plainPath() {
        assertThat(ZimUrls.forEntry("pack-1", "Photosynthesis"))
            .isEqualTo("https://zim.granger.invalid/pack-1/Photosynthesis")
        roundTrip("Photosynthesis")
    }

    @Test fun specialCharactersRoundTrip() {
        roundTrip("C++")
        roundTrip("What_is_this?")
        roundTrip("Café_au_lait")
        roundTrip("100%_Pure")
        roundTrip("A/Old_namespace_article")
        roundTrip("Emoji_😀")
        roundTrip("Space and \"quotes\" #hash")
    }

    @Test fun encodesReservedCharacters() {
        val url = ZimUrls.forEntry("p", "What_is_this?")
        assertThat(url).isEqualTo("https://zim.granger.invalid/p/What_is_this%3F")
        assertThat(ZimUrls.forEntry("p", "C++")).isEqualTo("https://zim.granger.invalid/p/C%2B%2B")
    }

    @Test fun keepsSlashesBetweenSegments() {
        assertThat(ZimUrls.forEntry("p", "I/leaf.png")).isEqualTo("https://zim.granger.invalid/p/I/leaf.png")
    }

    @Test fun rawPlusIsAPlusNotASpace() {
        assertThat(ZimUrls.parse("https://zim.granger.invalid/p/C++")).isEqualTo(ZimUrl("p", "C++"))
    }

    @Test fun keepsFragmentAndDropsQuery() {
        assertThat(ZimUrls.parse("https://zim.granger.invalid/p/Photosynthesis?x=1#s3"))
            .isEqualTo(ZimUrl("p", "Photosynthesis", "s3"))
        assertThat(ZimUrls.forEntry("p", "Photosynthesis", "s3"))
            .isEqualTo("https://zim.granger.invalid/p/Photosynthesis#s3")
    }

    @Test fun malformedEscapesAreKeptLiterally() {
        assertThat(ZimUrls.parse("https://zim.granger.invalid/p/100%_Pure%2")).isEqualTo(ZimUrl("p", "100%_Pure%2"))
    }

    @Test fun emptyPathParses() {
        assertThat(ZimUrls.parse("https://zim.granger.invalid/p/")).isEqualTo(ZimUrl("p", ""))
    }

    @Test fun foreignUrlsAreNotZimUrls() {
        assertThat(ZimUrls.parse("https://example.com/p/Photosynthesis")).isNull()
        assertThat(ZimUrls.parse("https://zim.granger.invalid.evil.com/p/x")).isNull()
        assertThat(ZimUrls.parse("http://zim.granger.invalid/p/x")).isNull()
```

```kotlin
package app.granger.core.zim

import java.io.ByteArrayOutputStream

/** A reader URL split into its pack and the ZIM entry path inside it. `fragment` is kept raw. */
data class ZimUrl(val packId: String, val path: String, val fragment: String? = null)

/**
 * Reader URLs look like `https://zim.granger.invalid/<packId>/<path>`. The `.invalid` TLD never resolves,
 * so a request that escapes interception cannot reach the network. Path segments are percent-encoded;
 * `+` is always a literal plus (ZIM paths such as `C++` contain it), never a space.
 */
object ZimUrls {
    const val HOST = "zim.granger.invalid"
    private const val PREFIX = "https://$HOST/"
    private const val UNRESERVED = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~"
    private const val HEX = "0123456789ABCDEF"

    fun forEntry(packId: String, path: String, fragment: String? = null): String =
        PREFIX + encode(packId) + "/" + path.split('/').joinToString("/") { encode(it) } +
            (fragment?.let { "#$it" } ?: "")

    fun parse(url: String): ZimUrl? {
        if (!url.startsWith(PREFIX, ignoreCase = true)) return null
        val afterHost = url.substring(PREFIX.length)
        val fragment = afterHost.substringAfter('#', "").ifEmpty { null }
        val beforeQuery = afterHost.substringBefore('#').substringBefore('?')
        val slash = beforeQuery.indexOf('/')
        if (slash <= 0) return null
        return ZimUrl(decode(beforeQuery.substring(0, slash)), decode(beforeQuery.substring(slash + 1)), fragment)
    }

    private fun encode(segment: String): String = buildString {
        for (byte in segment.toByteArray(Charsets.UTF_8)) {
            val b = byte.toInt() and 0xFF
            if (b < 0x80 && UNRESERVED.indexOf(b.toChar()) >= 0) {
                append(b.toChar())
            } else {
                append('%').append(HEX[b shr 4]).append(HEX[b and 0xF])
            }
        }
    }

    private fun decode(s: String): String {
        if ('%' !in s) return s
        val out = ByteArrayOutputStream()
        var i = 0
        while (i < s.length) {
            if (s[i] == '%' && i + 2 < s.length) {
                val hi = Character.digit(s[i + 1], 16)
                val lo = Character.digit(s[i + 2], 16)
                if (hi >= 0 && lo >= 0) {
                    out.write(hi * 16 + lo)
                    i += 3
                    continue
                }
            }
            val codePoint = s.codePointAt(i)
            out.write(String(Character.toChars(codePoint)).toByteArray(Charsets.UTF_8))
            i += Character.charCount(codePoint)
        }
        return out.toString(Charsets.UTF_8.name())
    }
}
```

Note the boundary in `decode`: `i + 2 < s.length` means both hex digits exist. A trailing `%2` (one digit) falls through and is kept literally, which `malformedEscapesAreKeptLiterally` pins.

```kotlin
    val description: String,

    val date: String,

    val uuid: String
    val metadata: ZimMetadata

    fun suggest(query: String, limit: Int): List<ZimHit>

    fun search(query: String, limit: Int): List<ZimHit>

    override fun close()
}

    class Opened(val archive: ZimArchive) : ZimOpenResult
    data class Failed(val reason: String) : ZimOpenResult
}
```

```kotlin
package app.granger.core.zim

/** What the reader's WebView gets for one request. */
sealed interface ZimResponse {
    class Content(val mimeType: String, val encoding: String?, val bytes: ByteArray) : ZimResponse
    data object NotFound : ZimResponse
    /** Anything that is not a reader URL. Answered locally so it never reaches the network. */
    data object Blocked : ZimResponse
}

/** What to do when the reader taps a link. */
sealed interface LinkAction {
    /** Let the WebView load it. */
    data object Load : LinkAction
    /** The entry is a redirect; load the canonical URL so relative links on the target page resolve. */
    data class Redirect(val url: String) : LinkAction
    /** Leave the app (system browser, mail, maps). */
    data class External(val url: String) : LinkAction
    /** javascript:, file:, intent: and anything else unsafe. */
    data object Ignore : LinkAction
}

class ZimResolver(private val archiveFor: (packId: String) -> ZimArchive?) {
    fun response(url: String): ZimResponse {
        val zim = ZimUrls.parse(url) ?: return ZimResponse.Blocked
        val item = archiveFor(zim.packId)?.read(zim.path) ?: return ZimResponse.NotFound
        val (mimeType, encoding) = splitMimeType(item.mimeType)
        return ZimResponse.Content(mimeType, encoding, item.bytes)
    }

    fun linkAction(url: String): LinkAction {
        val zim = ZimUrls.parse(url)
            ?: return if (url.substringBefore(':', "").lowercase() in EXTERNAL_SCHEMES) {
                LinkAction.External(url)
            } else {
                LinkAction.Ignore
            }
        val target = archiveFor(zim.packId)?.resolvePath(zim.path) ?: return LinkAction.Load
        return if (target == zim.path) {
            LinkAction.Load
        } else {
            LinkAction.Redirect(ZimUrls.forEntry(zim.packId, target, zim.fragment))
        }
    }

    companion object {
        private val EXTERNAL_SCHEMES = setOf("http", "https", "mailto", "tel", "geo")
        private val TEXT_TYPES = setOf("application/javascript", "application/json", "application/xml", "image/svg+xml")

        /** Splits `text/html; charset=utf-8` into the MIME type and encoding WebResourceResponse wants. */
        fun splitMimeType(raw: String): Pair<String, String?> {
            val parts = raw.split(';').map { it.trim() }
            val mimeType = parts.first().lowercase().ifEmpty { "application/octet-stream" }
            val charset = parts.drop(1)
                .firstOrNull { it.startsWith("charset=", ignoreCase = true) }
                ?.substringAfter('=')?.trim('"', ' ')
            val isText = mimeType.startsWith("text/") || mimeType in TEXT_TYPES
            return mimeType to (charset ?: if (isText) "UTF-8" else null)
        }
    }
}
```

```kotlin
package app.granger.core.zim

import org.kiwix.libzim.Archive
import org.kiwix.libzim.Query
import org.kiwix.libzim.Searcher
import org.kiwix.libzim.SuggestionSearcher
import java.util.concurrent.locks.ReentrantReadWriteLock
import kotlin.concurrent.read
import kotlin.concurrent.write

/**
 * [ZimArchive] over libkiwix. Reads run in parallel under a read lock; [close] takes the write lock,
 * so native objects are never used after they are disposed. Searchers are not thread-safe, so
 * searches are serialized on [searchLock].
 */
internal class KiwixZimArchive(private val archive: Archive, fallbackTitle: String) : ZimArchive {
    private val lock = ReentrantReadWriteLock()
    private var closed = false
    private val searchLock = Any()
    private var searcher: Searcher? = null
    private var suggester: SuggestionSearcher? = null

    override val uuid: String = archive.uuid
    override val metadata = ZimMetadata(
        title = meta("Title").ifBlank { fallbackTitle },
        description = meta("Description"),
        language = meta("Language"),
        date = meta("Date"),
        name = meta("Name"),
    )
    override val mainPath: String? =
        if (archive.hasMainEntry()) archive.mainEntry.getItem(true).path else null
    override val hasFulltextIndex: Boolean = archive.hasFulltextIndex()

    private fun meta(name: String): String =
        try { archive.getMetadata(name) } catch (e: Exception) { "" }

    private inline fun <T> reading(fallback: T, block: () -> T): T = lock.read {
        if (closed) fallback else try { block() } catch (e: Exception) { fallback }
    }

    override fun resolvePath(path: String): String? = reading(null) {
        if (archive.hasEntryByPath(path)) archive.getEntryByPath(path).getItem(true).path else null
    }

    override fun read(path: String): ZimItem? = reading(null) {
        if (!archive.hasEntryByPath(path)) return@reading null
        val item = archive.getEntryByPath(path).getItem(true)
        ZimItem(item.path, item.mimetype, item.data.data)
    }

    override fun suggest(query: String, limit: Int): List<ZimHit> = reading(emptyList()) {
        if (query.isBlank()) return@reading emptyList()
        synchronized(searchLock) {
            val suggester = suggester ?: SuggestionSearcher(archive).also { suggester = it }
            val results = suggester.suggest(query.trim()).getResults(0, limit)
            buildList {
                while (results.hasNext()) {
                    val item = results.next()
                    add(ZimHit(item.path, item.title))
                }
            }
        }
    }

    override fun search(query: String, limit: Int): List<ZimHit> = reading(emptyList()) {
        if (!hasFulltextIndex || query.isBlank()) return@reading emptyList()
        synchronized(searchLock) {
            val searcher = searcher ?: Searcher(archive).also { searcher = it }
            val results = searcher.search(Query(query.trim())).getResults(0, limit)
            buildList {
                while (results.hasNext()) {
                    // libkiwix's getters describe the entry the *next* call to next() returns,
                    // so read them before advancing.
                    val hit = ZimHit(
                        path = results.path,
                        title = results.title,
                        snippet = results.snippet?.takeIf { it.isNotBlank() },
                        score = results.score,
                    )
                    results.next()
                    add(hit)
                }
            }
        }
    }

    override fun close() = lock.write {
        if (closed) return@write
        closed = true
        searcher?.dispose()
        suggester?.dispose()
        archive.dispose()
    }
}
```

```kotlin
import android.content.Context
import org.kiwix.libkiwix.JNIKiwix
import org.kiwix.libzim.Archive

/** Opens ZIM files with libkiwix. Constructing it loads the native libraries once per process. */
class KiwixZimOpener(context: Context) : ZimOpener {
    init {
        loadNativeLibraries(context.applicationContext)
    }

    override fun open(file: File): ZimOpenResult {
        if (!file.isFile || !file.canRead()) return ZimOpenResult.Failed("Can't read ${file.path}")
        return try {
            ZimOpenResult.Opened(KiwixZimArchive(Archive(file.absolutePath), file.nameWithoutExtension))
        } catch (e: Exception) {
            ZimOpenResult.Failed(e.message ?: e.javaClass.simpleName)
        }
    }

    private companion object {
        private var loaded = false

        @Synchronized
        fun loadNativeLibraries(context: Context) {
            if (loaded) return
            JNIKiwix(context)
            loaded = true
        }
    }
}
```

- A known pack whose file is gone becomes `MISSING`; it returns to `OK` when the file comes back.
- The same ZIM (same UUID) in two folders is listed once. A different ZIM at a known path (a new snapshot) replaces the old row.
- `addedAt` survives refreshes. Any status change closes the cached archive for that pack.

`archive()` is blocking (a Room query plus a native open) and is called from the WebView's request thread and from `Dispatchers.IO`.

```kotlin
package app.granger.core.library

import app.granger.core.zim.ZimArchive
import app.granger.core.zim.ZimOpenResult
import app.granger.core.zim.ZimOpener
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.coroutines.withContext
import java.io.File

/**
 * [Library] backed by Room. Packs are the `*.zim` files in [packDirs] (one `packs` folder per
 * external-files volume); [refresh] reconciles the table with what is on disk.
 */
class RoomLibrary(
    db: LibraryDatabase,
    private val opener: ZimOpener,
    private val packDirs: () -> List<File>,
    private val io: CoroutineDispatcher = Dispatchers.IO,
    private val now: () -> Long = System::currentTimeMillis,
) : Library {
    private val packDao = db.packDao()
    private val bookmarkDao = db.bookmarkDao()
    private val positionDao = db.readingPositionDao()
    private val refreshMutex = Mutex()
    private val openArchives = HashMap<String, ZimArchive>()

    override val packs: Flow<List<Pack>> = packDao.observeAll()
    override val bookmarks: Flow<List<Bookmark>> = bookmarkDao.observeAll()

    override suspend fun refresh() = refreshMutex.withLock {
        withContext(io) {
            val known = packDao.getAll()
            val files = packDirs()
                .flatMap { dir -> dir.listFiles()?.toList().orEmpty() }
                .filter { it.isFile && it.name.endsWith(".zim", ignoreCase = true) }
                .sortedBy { it.absolutePath }
            val seenPaths = HashSet<String>()
            val seenIds = HashSet<String>()
            for (file in files) {
                val path = file.absolutePath
                seenPaths += path
                val previous = known.firstOrNull { it.filePath == path }
                val pack = when (val result = opener.open(file)) {
                    is ZimOpenResult.Opened -> result.archive.use { Pack.from(it, file, previous?.addedAt ?: now()) }
                    is ZimOpenResult.Failed ->
                        previous?.copy(status = PackStatus.CORRUPT, sizeBytes = file.length())
                            ?: Pack.unreadable(file, now())
                }
                if (!seenIds.add(pack.id)) continue // the same ZIM in two folders: keep the first
                if (previous != null && previous.id != pack.id) {
                    // A different ZIM now sits at this path (e.g. a newer snapshot).
                    packDao.delete(previous.id)
                    closeArchive(previous.id)
                }
                if (pack != previous) {
                    packDao.upsert(pack)
                    closeArchive(pack.id)
                }
            }
            for (pack in known) {
                if (pack.filePath !in seenPaths && pack.status != PackStatus.MISSING) {
                    packDao.upsert(pack.copy(status = PackStatus.MISSING))
                    closeArchive(pack.id)
                }
            }
        }
    }

    override fun archive(packId: String): ZimArchive? {
        synchronized(openArchives) { openArchives[packId]?.let { return it } }
        val pack = packDao.get(packId)?.takeIf { it.status == PackStatus.OK } ?: return null
        val opened = (opener.open(File(pack.filePath)) as? ZimOpenResult.Opened)?.archive ?: return null
        synchronized(openArchives) {
            openArchives[packId]?.let { existing ->
                opened.close() // another thread won the race
                return existing
            }
            openArchives[packId] = opened
            return opened
        }
    }

    private fun closeArchive(packId: String) {
        synchronized(openArchives) { openArchives.remove(packId) }?.close()
    }

    override suspend fun startPath(packId: String): String? = withContext(io) {
        val archive = archive(packId) ?: return@withContext null
        positionDao.lastRead(packId)?.path?.takeIf { archive.resolvePath(it) != null } ?: archive.mainPath
    }

    override fun isBookmarked(packId: String, path: String): Flow<Boolean> =
        bookmarkDao.observeExists(packId, path)

    override suspend fun setBookmarked(packId: String, path: String, title: String, bookmarked: Boolean) {
        if (bookmarked) {
            bookmarkDao.upsert(Bookmark(packId, path, title, now()))
        } else {
            bookmarkDao.delete(packId, path)
        }
    }

    override suspend fun savePosition(packId: String, path: String, scrollFraction: Float) {
        val fraction = if (scrollFraction.isNaN()) 0f else scrollFraction.coerceIn(0f, 1f)
        positionDao.upsert(ReadingPosition(packId, path, fraction, now()))
    }

    override suspend fun position(packId: String, path: String): Float? =
        positionDao.get(packId, path)?.scrollFraction
}
```

```kotlin
package app.granger.core.library

import app.granger.core.zim.ZimArchive
import app.granger.core.zim.ZimHit
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.withContext

/** One search result. [snippet] is HTML with `<b>` highlights, set only for full-text results. */
data class SearchHit(
    val packId: String,
    val packTitle: String,
    val path: String,
    val title: String,
    val snippet: String? = null,
)

/** Searches every OK pack. Plan 5 replaces the implementation with `:core:search` sources. */
interface LibrarySearch {
    suspend fun titles(query: String): List<SearchHit>
    suspend fun fullText(query: String): List<SearchHit>
}

class ZimLibrarySearch(
    private val library: Library,
    private val io: CoroutineDispatcher = Dispatchers.IO,
    private val titlesPerPack: Int = 8,
    private val fullTextLimit: Int = 30,
) : LibrarySearch {
    override suspend fun titles(query: String): List<SearchHit> =
        across(query) { it.suggest(query, titlesPerPack) }.map { it.second }

    override suspend fun fullText(query: String): List<SearchHit> =
        across(query) { if (it.hasFulltextIndex) it.search(query, fullTextLimit) else emptyList() }
            .sortedByDescending { it.first.score }
            .take(fullTextLimit)
            .map { it.second }

    /** Runs [run] on each OK pack; a pack that fails is skipped so the others still answer. */
    private suspend fun across(query: String, run: (ZimArchive) -> List<ZimHit>): List<Pair<ZimHit, SearchHit>> {
        if (query.isBlank()) return emptyList()
        val packs = library.packs.first().filter { it.status == PackStatus.OK }
        return withContext(io) {
            packs.flatMap { pack ->
                val archive = library.archive(pack.id) ?: return@flatMap emptyList()
                val hits = try { run(archive) } catch (e: Exception) { emptyList() }
                hits.map { hit -> hit to SearchHit(pack.id, pack.title, hit.path, hit.title, hit.snippet) }
            }
        }
    }
}
```

How the reader behaves:
- **Start page:** the requested path (from search or a bookmark), else the last article read in that pack if it still exists, else the main page.
- **Reading position** is a scroll fraction saved per pack + path when a link is followed, on WebView back, and on `ON_PAUSE` (app backgrounded, screen left or popped). It is restored after `onPageFinished` unless the URL has a `#fragment`, which wins. Writes go to `appScope` so popping the screen can't cancel them.
- **Rotation:** the ViewModel survives; `state.url` tracks the current page, so the new WebView reloads it and `ON_PAUSE` has already saved the scroll position to restore.
- **Links:** in-pack links load normally; redirect entries load their canonical URL; `http(s)`, `mailto`, `tel`, `geo` open another app via `ACTION_VIEW` (a toast if none can); `javascript:`, `file:`, `intent:` do nothing. Subresources for anything but the ZIM host get an empty 403, so the reader makes no network requests.
- **Title** is the document `<title>`, else the last path segment with `_` → space.

```kotlin
        val page: Page? = null,
        val bookmarked: Boolean = false,
        val error: String? = null,
    )

    private val _state = MutableStateFlow(State())
    val state: StateFlow<State> = _state.asStateFlow()
    private val page = MutableStateFlow<Page?>(null)

    init {
        viewModelScope.launch {
            if (withContext(io) { library.archive(packId) } == null) {
                _state.update { it.copy(error = PACK_UNAVAILABLE) }
                return@launch
            }
            val path = requestedPath ?: library.startPath(packId)
            if (path == null) {
                _state.update { it.copy(error = NO_MAIN_PAGE) }
                return@launch
            }
            _state.update { it.copy(url = ZimUrls.forEntry(packId, path)) }
        }
        viewModelScope.launch {
            page.flatMapLatest { p -> if (p == null) flowOf(false) else library.isBookmarked(packId, p.path) }
                .collect { bookmarked -> _state.update { it.copy(bookmarked = bookmarked) } }
        }
    }

    /**
     * The WebView finished loading [url]. [documentTitle] is null when the page has none.
     * Returns the scroll fraction to restore, or null to stay at the top (or at the URL's #fragment).
     */
    suspend fun onPageShown(url: String, documentTitle: String?): Float? {
        val zim = ZimUrls.parse(url)?.takeIf { it.packId == packId } ?: return null
        val title = documentTitle?.takeIf { it.isNotBlank() }
            ?: zim.path.substringAfterLast('/').replace('_', ' ')
        val shown = Page(zim.path, title)
        page.value = shown
        _state.update { it.copy(url = url, page = shown) }
        return if (zim.fragment != null) null else library.position(packId, zim.path)
    }

    fun savePosition(url: String?, scrollFraction: Float) {
        val zim = url?.let(ZimUrls::parse)?.takeIf { it.packId == packId } ?: return
        appScope.launch { library.savePosition(packId, zim.path, scrollFraction) }
    }

    fun toggleBookmark() {
        val current = page.value ?: return
        val add = !_state.value.bookmarked
        appScope.launch { library.setBookmarked(packId, current.path, current.title, add) }
    }

    companion object {
        const val PACK_UNAVAILABLE =
            "This pack is missing or damaged. Check that its file is still on the phone or SD card."
        const val NO_MAIN_PAGE = "This pack has no main page. Use Search to open an article."
    }
}
```

```kotlin
package app.granger.reader

import android.webkit.WebResourceRequest
import android.webkit.WebResourceResponse
import android.webkit.WebView
import android.webkit.WebViewClient
import app.granger.core.zim.LinkAction
import app.granger.core.zim.ZimResolver
import app.granger.core.zim.ZimResponse
import java.io.ByteArrayInputStream

/**
 * Serves every request from the ZIM (the Kiwix approach) and blocks everything else, so the reader
 * never touches the network. Callbacks run on the main thread.
 */
class ZimWebViewClient(
    private val resolver: ZimResolver,
    private val onExternalLink: (url: String) -> Unit,
    private val onLeavingPage: (WebView) -> Unit,
    private val onPageShown: (WebView, url: String) -> Unit,
) : WebViewClient() {
    override fun shouldInterceptRequest(view: WebView, request: WebResourceRequest): WebResourceResponse =
        when (val response = resolver.response(request.url.toString())) {
            is ZimResponse.Content ->
                WebResourceResponse(response.mimeType, response.encoding, ByteArrayInputStream(response.bytes))
            ZimResponse.NotFound ->
                WebResourceResponse("text/html", "UTF-8", 404, "Not Found", emptyMap(), ByteArrayInputStream(NOT_FOUND))
            ZimResponse.Blocked ->
                WebResourceResponse("text/plain", "UTF-8", 403, "Forbidden", emptyMap(), ByteArrayInputStream(ByteArray(0)))
        }

    override fun shouldOverrideUrlLoading(view: WebView, request: WebResourceRequest): Boolean {
        if (!request.isForMainFrame) return false
        return when (val action = resolver.linkAction(request.url.toString())) {
            LinkAction.Load -> {
                onLeavingPage(view)
                false
            }
            is LinkAction.Redirect -> {
                onLeavingPage(view)
                view.loadUrl(action.url)
                true
            }
            is LinkAction.External -> {
                onExternalLink(action.url)
                true
            }
            LinkAction.Ignore -> true
        }
    }

    override fun onPageFinished(view: WebView, url: String) {
        onPageShown(view, url)
    }

    private companion object {
        val NOT_FOUND =
            "<html><body><p>This page isn't in this pack.</p></body></html>".toByteArray()
    }
}
```

```kotlin
package app.granger.reader

import android.annotation.SuppressLint
import android.content.Context
import android.webkit.WebView

/** A WebView configured for ZIM content that can report and restore how far down the page it is. */
@SuppressLint("SetJavaScriptEnabled", "ViewConstructor")
class ReaderWebView(context: Context, client: ZimWebViewClient) : WebView(context) {
    init {
        settings.javaScriptEnabled = true // Wikipedia ZIMs use JS for collapsible sections
        settings.domStorageEnabled = true
        settings.allowFileAccess = false
        settings.allowContentAccess = false
        settings.builtInZoomControls = true
        settings.displayZoomControls = false
        webViewClient = client
    }

    /** 0 at the top, 1 at the bottom; 0 when the page does not scroll. */
    fun scrollFraction(): Float {
        val range = computeVerticalScrollRange() - height
        return if (range <= 0) 0f else (scrollY.toFloat() / range).coerceIn(0f, 1f)
    }

    fun scrollToFraction(fraction: Float) {
        evaluateJavascript(
            "window.scrollTo(0, (document.documentElement.scrollHeight - window.innerHeight) * $fraction)",
            null,
        )
    }
}
```

```kotlin
package app.granger.search

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import app.granger.core.library.LibrarySearch
import app.granger.core.library.SearchHit
import kotlinx.coroutines.FlowPreview
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.collectLatest
import kotlinx.coroutines.flow.debounce
import kotlinx.coroutines.flow.distinctUntilChanged
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

@OptIn(FlowPreview::class)
class SearchViewModel(private val search: LibrarySearch) : ViewModel() {
    data class State(
        val query: String = "",
        val titles: List<SearchHit> = emptyList(),
        /** Full-text hits whose article is not already in [titles]. */
        val fullText: List<SearchHit> = emptyList(),
        val searching: Boolean = false,
    )

    private val query = MutableStateFlow("")
    private val _state = MutableStateFlow(State())
    val state: StateFlow<State> = _state.asStateFlow()

    init {
        viewModelScope.launch {
            query.debounce(DEBOUNCE_MS).distinctUntilChanged().collectLatest { q ->
                if (q.isBlank()) {
                    _state.update { it.copy(titles = emptyList(), fullText = emptyList(), searching = false) }
                    return@collectLatest
                }
                _state.update { it.copy(searching = true) }
                val titles = search.titles(q)
                _state.update { it.copy(titles = titles) }
                val shown = titles.map { it.packId to it.path }.toSet()
                val fullText = search.fullText(q).filterNot { (it.packId to it.path) in shown }
                _state.update { it.copy(fullText = fullText, searching = false) }
            }
        }
    }

    fun onQueryChange(text: String) {
        query.value = text.trim()
        _state.update { it.copy(query = text) }
    }

    companion object {
        const val DEBOUNCE_MS = 250L
    }
}
```

```kotlin
package app.granger.bookmarks

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import app.granger.core.library.Bookmark
import app.granger.core.library.Library
import app.granger.core.library.PackStatus
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch

class BookmarksViewModel(private val library: Library, private val appScope: CoroutineScope) : ViewModel() {
    data class Row(val bookmark: Bookmark, val packTitle: String, val available: Boolean)

    /** Newest first; null until loaded. Bookmarks in missing or damaged packs stay listed but disabled. */
    val rows: StateFlow<List<Row>?> = combine(library.bookmarks, library.packs) { bookmarks, packs ->
        val byId = packs.associateBy { it.id }
        bookmarks.map { b ->
            val pack = byId[b.packId]
            Row(b, pack?.title ?: REMOVED_PACK, pack?.status == PackStatus.OK)
        }
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), null)

    fun remove(bookmark: Bookmark) {
        appScope.launch { library.setBookmarked(bookmark.packId, bookmark.path, bookmark.title, false) }
    }

    companion object {
        const val REMOVED_PACK = "Removed pack"
    }
}
```

```bash
#!/usr/bin/env bash
# Downloads a small real Wikipedia ZIM (verified), then pushes it and the test ZIM to the phone's
# pack folder, where the Library screen finds them on its next resume.
set -euo pipefail
cd "$(dirname "$0")/../.."

PACKS_DIR="${PACKS_DIR:-$HOME/granger-packs}"
TARGET=/sdcard/Android/data/app.granger/files/packs
NAME=wikipedia_en_ray-charles_maxi_2026-08.zim
SHA256=74f9d80ad6183ede02e5c6f4a023676444c0c212889ed0dd9496f3738f72b976

mkdir -p "$PACKS_DIR"
if [[ ! -f "$PACKS_DIR/$NAME" ]]; then
  curl -L --fail -o "$PACKS_DIR/$NAME.part" "https://download.kiwix.org/zim/wikipedia/$NAME"
  mv "$PACKS_DIR/$NAME.part" "$PACKS_DIR/$NAME"
fi
echo "$SHA256  $PACKS_DIR/$NAME" | sha256sum -c -

adb shell mkdir -p "$TARGET"
adb push "$PACKS_DIR/$NAME" "$TARGET/$NAME"
adb push testdata/granger-test.zim "$TARGET/granger-test.zim"
adb shell ls -l "$TARGET"
```
