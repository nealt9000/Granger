# TalkBack by ear (Plan O7): about ten minutes

The accessibility tree tells me each control has a label and a place in the order. It can't tell whether the result
sounds right. This is for a person with headphones on.

**Before:** Settings → Accessibility → TalkBack on. Swipe right to move to the next item, double-tap to press it, and
swipe down then right to go back.

For each step, note anything that's read twice, read as a bare word ("Button", "Image"), read in a strange order, or
skipped.

## 1. Welcome and Outfit

Welcome only shows on a fresh install, so do this one on the Pixel 7 after I've installed a fresh build there. Outfit
also opens from Settings → Outfit for offline.

- [ ] The intro is read as one passage, then "Start reading now", then "Outfit for offline".
- [ ] The privacy line is read in full once, not split.
- [ ] On Outfit, "A start", "Your region" and "For" are announced as headings.
- [ ] The footer reads the total before "Review".

## 2. A topic page (search "Lake Turkana" and open it)

- [ ] The trail reads "Explore, …, Rivers, mountains & seas", and each step is announced as a button.
- [ ] "More in Rivers, mountains & seas" is a heading; "All" follows it.
- [ ] Each tile reads its title, then its line, once.
- [ ] The time card's rows read "name, years" as one item.

## 3. Keep (any online article)

- [ ] "Keep · 180 KB" is read as one button.
- [ ] After a double-tap, the hint under it is read once, and "Kept, Remove" replaces the button.

## 4. Local only (top bar's cloud button)

- [ ] The button reads "Local only, switch, Off" (then "On" after a double-tap).
- [ ] The banner is read when it appears, then the hint once.
- [ ] Back on the topic page, a greyed tile reads "…, Needs internet"; double-tap opens "what it would take".
